# Web 云管理面板指南

[English](./en/cloud.md)

R-Bot 客户端内置了完整的 Web 云管理面板，在浏览器中即可管理 Oracle Cloud、AWS、GCP、Azure、DigitalOcean、SolusVM、VirtFusion、Cloudflare DNS 等多云平台资源，操作能力与 Telegram 机器人对齐。

---

## 访问方式

启动客户端后，访问：

```
https://你的IP:9527
```

登录后在主机面板中点击云管理相关入口，或通过视图切换进入云管理工作台。

> 首次使用需先在顶部栏「设置」中配置云平台 Profile（或通过 `client_config` 文件配置）。

---

## 概览面板

登录后的首页展示当前 Profile 的概览信息：

| 卡片 | 内容 |
|------|------|
| **成本** | 近 3 个月花费明细 |
| **流量** | 近 3 个月流量使用量 |
| **订阅** | 订阅类型、支付方式、有效期 |
| **配额** | 实例、网络、存储配额使用情况 |

支持切换不同的 Profile 查看不同账户的信息。

## 云监控

工作台的「云监控」标签页，两组规则，与机器人端的实例监控是同一份配置，任一端改动另一端同步。

### 流量守护（按账号）

OCI 免费额度为每月 10240 GB，超出按量计费。为账号设一个当月流量阈值，达到后触发。

| 项目 | 说明 |
|------|------|
| 监控账号 | 按 Profile 逐个设置 |
| 流量阈值 | 单位 GB。账单数据有 4~24 小时延迟，建议填 9000 而非贴着上限，留出止损时间 |
| 仅通知我 | 只发 Telegram，不动实例 |
| 自动关机 | 立即关停该账号**全部区域**的实例（SOFTSTOP 优雅停机），触发即执行，无二次确认 |
| 当月用量 | 来自 Oracle 账单接口，非实时值 |

选自动关机需要知道：手动开机后若仍超阈，最迟 1 小时内会被再次关停；关机时间过长，A1 等抢手机型的容量配额可能被 Oracle 回收，重开需要重新抢机。

### 停机保活（全部账号）

| 开关 | 说明 |
|------|------|
| 实例停机通知 | 每 8 分钟检查一次，实例意外停机时发 Telegram |
| 停机自动开机 | 检测到停机自动启动；被流量守护关停的账号当月不会自动开机，避免继续跑流量 |

## 域名监控

工作台的「域名监控」标签页。每日定时检查域名注册到期和 SSL 证书到期，临期通过 Telegram 提醒。

| 操作 | 说明 |
|------|------|
| 添加域名 | 手动添加单个域名 |
| 从 Cloudflare 导入 | 批量导入 Cloudflare 托管的域名，同名跳过，超出数量上限时提示未导入的部分 |
| 到期提醒开关 | 逐个域名开关提醒 |
| 立即检查 | 不等定时任务，当场探测一次 |
| 搜索 | 支持中文域名，自动转 punycode 匹配 |
| 删除 | 删除后不再监控 |

提醒档位为 30 / 14 / 7 / 1 天及已过期，按档位去重，同一档只提醒一次。

建议填注册域名（如 `example.com`）。子域名查不到注册信息，域名到期会显示「未知」，证书检查不受影响。单次检查失败时保留上一次的数据并标为「未知」，不覆盖已知值。

权限范围：添加、导入、开启提醒需要闪电权益；停用、删除、查看和「立即检查」不需要。

### 云平台配置管理

在 Web 界面中直接上传、编辑和管理云平台 API 配置，覆盖 OCI/AWS/GCP/Azure/DO/SolusVM/VirtFusion 共 7 种云，无需手动编辑 `client_config` 文件。

| 功能 | 说明 |
|------|------|
| OCI 配置上传 | 粘贴 API 配置文本 + 上传 PEM 密钥文件，自动配置 key_file 路径 |
| AWS 配置上传 | 粘贴 Access Key ID / Secret Access Key 配置 |
| GCP 配置上传 | 上传 Service Account JSON 密钥文件，自动提取凭据 |
| DO 配置上传 | 粘贴 DigitalOcean API Token |
| Azure 配置上传 | 粘贴 appId/password/tenant 配置 |
| SolusVM 配置上传 | 粘贴 API 地址和密钥配置 |
| VirtFusion 配置上传 | 粘贴 host/token/preset 或使用预置厂商快速填充 |
| 合并模式 | 同名 Profile 自动跳过并提醒，新 Profile 追加到配置中 |
| Profile 在线编辑 | 已配置的 Profile 以标签列表展示，点开即可就地修改字段，改字段不再需要 SSH 改文件 |
| Profile 复制为新地区 | OCI / AWS 的 Profile 可一键复制成另一区域的新 Profile，只替换区域，AWS 可用区形态自动归一化 |
| API 出站代理 | 在 Profile 编辑面板底部按账号配置出站代理；停用需点「移除代理」，清空输入框保存不算停用 |
| 删除单个 Profile | 删除指定 Profile，并同步清理默认 Profile 的悬挂引用 |
| 密钥掩码 | 密钥 / Token 等敏感字段以掩码展示，明文永不下发 |
| AWS 区域校正 | region 误填成可用区（如 ap-southeast-1a）时实时提示并支持一键修正 |
| Cloudflare 配置 | 在线编辑 Cloudflare 凭据。支持 API Token（权限只需 Zone→DNS→Edit 与 Zone→Zone→Read）和 Global API Key 两种方式，两者并存时以 Token 为准 |
| 网络配置 | 在线编辑本机地址、URL 名称、启动模式 |
| 配置热加载 | 保存后即时热加载生效，也可手动刷新内存配置，均无需重启客户端 |

## 云实例一键 SSH

所有云平台（OCI / AWS EC2 / AWS Lightsail / GCP / Azure / DO / SolusVM / VirtFusion）的实例卡片上均提供「SSH」快捷按钮，点击后直接跳转到终端并连接该实例，无需手动填写连接信息。每张卡片还提供 IP 一键复制按钮。

## 各云体检面板

汇总展示所有云平台的实例总量、运行/停止数、DNS 信息等关键指标，一屏纵览多云资产健康度。

## 工作台体验

- **按优先级排序** — 云平台标签页按使用频率排列（OCI、AWS、Azure、GCP、DO、Cloudflare、SolusVM、VirtFusion）
- **表单化配置上传** — 配置上传改为表单输入，无需手写格式
- **按钮分组重排** — 实例操作按钮按使用频率分组排列
