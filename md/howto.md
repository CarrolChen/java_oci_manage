## 换 IP 并自动更新 DNS

IP 被墙之后最常做的操作。换完 IP 顺手把域名解析改掉，效果等同 DDNS。

**准备**：先在「设置 → 配置文件设置」里填 Cloudflare 凭据，两种任选：

| 方式 | 填什么 | 获取路径 |
|------|--------|---------|
| API Token（推荐） | `cf_api_token` | Cloudflare 后台创建，权限勾 Zone→DNS→Edit 和 Zone→Zone→Read |
| Global API Key | `cf_email` + `cf_account_key` | 我的个人资料 → API 令牌 → API 密钥 → Global API Key |

两个都填时以 Token 为准。Token 是最小权限，Global API Key 一把钥匙管整个账户，能用 Token 就别用它。

**机器人端**：`/oracle` → 「2. ip管理」。里面几个操作：

- 换 IP
- 把当前 IP 分配给 Cloudflare 上托管的域名
- 换 IP 的同时更新该 IP 已绑定域名的解析记录（伪 DDNS）
- 删除域名 — 清空当前 IP 绑定的所有域名
- 删掉当前 IP

**Web 端**：云管理 → 实例卡片 → 网络/IP 操作，能换 IPv4、换 IPv6、附加额外 IPv4、附加 IPv6、附加保留 IP。DNS 记录在「Cloudflare」标签页里直接增删改。

## IP 不通时自动换

不用自己盯着。`/oracle` → 「16. 监控(自动换ip)」。

设置项：

- 要监控的 IP
- 是否走代理判断（不走代理就以客户端所在机器为基准判断连通性）
- 奈飞非自制剧检测
- 指定 IP 段 — 换出来的 IP 不在这个段里就继续换

触发后自动换 IP 并按你配的规则更新域名绑定。

## 流量超额自动关机

OCI 免费额度每月 10240 GB（10TB），超出按量扣费。被刷流量一晚上扣掉几十刀是常见事故。

云管理 → 「云监控」 → 「+ 新增流量守护」：

1. 选要监控的账号
2. 填当月流量阈值，**建议 9000 而不是 10240** — 甲骨文账单数据有 4~24 小时延迟，卡着上限填等于来不及
3. 动作选「仅通知我」或「自动关机」

选自动关机要知道这几点：

- 触发即执行，没有二次确认，关的是该账号**全部区域**的实例（SOFTSTOP 优雅停机）
- 手动开回来之后如果还超阈，最迟 1 小时内会被再次关掉
- 关机时间太长，A1 这类抢手机型的容量配额可能被甲骨文回收，重开要重新抢

规则里显示的当月用量同样来自账单接口，有延迟，不是实时值。

## 机器停了自动开回来

云管理 → 「云监控」 → 停机保活，两个开关：

| 开关 | 行为 |
|------|------|
| 实例停机通知 | 每 8 分钟检查一次，发现意外停机发 Telegram |
| 停机自动开机 | 停了就自动开回来 |

被流量守护关掉的账号，当月不会被自动开机 — 否则刚关就开，流量继续跑。

机器人端对应「9. 实例状态监控通知」和「10. 实例状态监控自启」，两边是同一份配置。

## A1 免费额度体检

甲骨文的 ARM 免费额度是账号级的，超开的账号可能被回收。云管理 → 「A1 配置体检」可以批量查和批量降。

1. **配置体检** — 并行扫各账号当前区域的 A1 用量，标出「超开 / 已符合额度 / 查询失败」
2. **降配** — 三种粒度：账号降配（在该账号多台实例间均分目标配置）、批量降配（全选可降的账号一次提交）、逐台降配
3. 目标配置默认推荐 2 核 12G，可改

几条硬规则：

- 只降不升，**绝不自动删实例**
- 降配走的是抢机式 resize，撞到容量不足会自动重试直到成功，结果发 Telegram，任务列表里可以取消
- 运行中的实例降配时会重启
- 目标 OCPU 数不能少于该账号实例数，否则均分不了，得先逐台降或删掉几台
- 删实例只能逐台手动确认，不提供批量删

非闪电用户只能体检当前账号，闪电用户可以一次体检和降配全部账号。

## 域名和证书到期监控

云管理 → 「域名监控」。每天 04:25 自动检查一遍域名注册到期和 SSL 证书到期，快到期时发 Telegram。

添加方式两种：手动填域名，或者「从 Cloudflare 导入」把托管的域名一次拉进来（有数量上限，超了会提示哪些没导入）。

提醒档位是 30 天、14 天、7 天、1 天和已过期，同一档只提醒一次，不会天天轰炸。

几个注意点：

- 填**注册域名**（`example.com`），别填子域名。子域名查不到注册信息，域名到期会显示「未知」，证书到期不受影响
- 检查失败时保留上一次的数据并标为「未知」，不会把已知值冲掉
- 搜索框支持中文域名，自动转 punycode 匹配
- 添加、导入、开启提醒需要闪电权益；停用、删除、查看和「立即检查」不需要

## 给每个账号配独立出站 IP

多个甲骨文账号都从同一台客户端发 API 请求，出口 IP 是同一个。想让某些账号走各自的代理，按 Profile 单独配。

**Web 端**：设置 → 配置文件设置 → 点开要改的 Profile → 面板底部「API 出站代理」。填代理地址，需要认证再填用户名密码，无认证就留空，点「保存代理」。

停用必须点「移除代理」。把输入框清空再保存不算停用。

概览页的 Profile 列表有「出站代理」列，哪些号配了一眼能看出来，点进去直接跳到配置表单。

**机器人端**：`/oproxy`。

配了代理的账号请求全程走代理，不会在失败时偷偷回落到直连。地址写错会当场报错而不是静默使用真实 IP。

## 进不去系统时救机器

SSH 连不上、防火墙把自己关外面了、系统起不来 — 用串行控制台。

云管理 → 实例 → 串行控制台。客户端会自动生成临时密钥建立连接，浏览器里直接出终端。

连上之后如果系统本身已经坏了，可以用内置的 Netboot.xyz 引导：它会自动识别 UEFI/GRUB 菜单并引导进救援系统，危险步骤前会停下来等你确认。

连接 30 分钟后密钥自动过期，过期连接定时清理，不用手动收拾。

## 一次给多台机器执行命令

Web SSH 终端 → 批量命令。选中多台主机，输入命令，一次性下发。

结果在工作台里按主机分开显示，可以接着在同一批主机上继续执行下一条，不用重新选。

单台机器的临时命令也可以用机器人的 `/command`，在客户端所在服务器上执行。

## 把云上已有机器导进会话列表

不用一台台手填 IP。主机面板 → 云主机同步，支持 OCI、AWS EC2、AWS Lightsail、GCP、Azure、DigitalOcean、SolusVM、VirtFusion。

同步过来的是连接信息，用户名和密钥还得配一次。密钥在「SSH 密钥管理」里存一份，之后所有会话都能选。

各云的实例卡片上也有「SSH」按钮，点了直接跳终端连接，适合临时连一次。
